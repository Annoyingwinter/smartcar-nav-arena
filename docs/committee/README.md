**为什么原件只放一份**：其余教程 PDF（环境配置、控制教程、建图教程、图像教程、计时教程）
体积共约 4 MB，且它们的内容是"怎么装环境 / 怎么跑节点"，与本仓库的
[`DEPLOY.md`](../DEPLOY.md) 和 [`BENCHMARK.md`](../BENCHMARK.md) 高度重合；
唯一的例外是《控制教程》的"参数"一节 —— 维护者**逐页核对过**：它只列出 5 个参数文件的
**文件名**与各自用途，**没有给出任何数值**，因此它对"公共基线取值"没有提供考据价值。

细则原件保留在仓库里，是因为计分与红线必须能被第三方独立核对原文，
不能只依赖我们转述的 `细则-节选.md`。
