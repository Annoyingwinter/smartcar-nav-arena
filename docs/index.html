30 分钟上手

没接触过本项目的 AI / 人,按这四步走（细节在 DEPLOY.md）：

git clone <仓库URL> smartcar-nav-arena && cd smartcar-nav-arena
bash harness/bringup_container.sh     # 建镜像 + 起容器（首次 20~40 分钟）
bash harness/build_workspace.sh       # 编译 ROS 工作空间
bash harness/bench_run.sh smoke 600   # 环境自测：车不动是故意的
python3 harness/bench_score.py smoke

看到 "finished": false 就说明环境是通的 —— 默认 commander 是占位桩， 不含任何导航算法,也不含任何其他模型的算法。然后读 KNOWN_ISSUES.md,再开始写自己的 commander。
